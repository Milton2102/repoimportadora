# Importadora Larraín

Proyecto académico de una tienda online de productos electrónicos para la asignatura **Desarrollo Fullstack II (DSY1104)**.

El sitio permite presentar productos, registrar usuarios, iniciar sesión y enviar consultas. Además incluye documentación de requisitos del proyecto.

## Tecnologías utilizadas

- HTML5 para la estructura de las páginas.
- CSS3 para estilos y diseño responsive.
- JavaScript para validaciones de formularios.
- XAMPP para ejecutar el sitio localmente.
- ChatGPT.
- Gemini.

## Páginas disponibles

- `principal.html`: página de inicio y productos destacados.
- `productos.html`: catálogo de productos importados.
- `registroUsuarios.html`: formulario de registro de usuarios.
- `iniciarSesion.html`: formulario de correo y contraseña.
- `nosotros.html`: información de la empresa.
- `blogs.html`: artículos y consejos de tecnología.
- `contacto.html`: formulario de contacto validado.

## Validaciones implementadas

El formulario de contacto valida nombre, correo y comentario. Solo permite correos con los dominios `@duoc.cl`, `@profesor.duoc.cl` y `@gmail.com`.
